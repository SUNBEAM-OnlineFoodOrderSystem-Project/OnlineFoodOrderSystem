# Admin UI (Vite + React + MUI) - Mock Data

## Setup

1. Install dependencies:
   ```
   npm install
   ```

2. Run dev server:
   ```
   npm run dev
   ```

3. Open `http://localhost:5173` (Vite default) and go to `/login`.

Use any email containing 'admin' to mock-login.

## Structure
- src/components - Layout & ProtectedRoute
- src/pages - All admin pages
- src/mock - Mock datasets
